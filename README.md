# alibaba-ai-search

> 来源分类：**市场技能** ｜ 导出批次：published

Use Alibaba AI Mode for intelligent product search and discovery. Use when: (1) using natural language queries, (2) getting AI-powered recommendations, or (3) exploring AI sourcing features. All URLs include traffic_type=ags_llm tracking parameter.

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/alibaba-ai-search__skillhub        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/alibaba-ai-search__skillhub   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。

- 本技能从本地 WorkBuddy 环境导出，**所有真实密钥已脱敏为占位符**，使用前请配置你自己的 API Key。
